# MyExTookTheRouterAndTheDog

Entry for the [make.fun bounty "Tell a Whole Story in 32 Characters"](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978): a single Wi-Fi network name of at most 32 characters that lands a joke and implies a whole story.

## The name

```
MyExTookTheRouterAndTheDog
```

26 characters. A passer-by sees it in a phone's network list and gets the whole story in one line: a break-up, an ex who walked out, and the double loss of both the router and the dog. The router is the Wi-Fi itself, so the joke is about the very network broadcasting it; the dog is the twist that makes the loss sting. Situation, character, and something that happened — in 26 characters, with no stock Wi-Fi joke in sight.

## How it works

`main.py` is deterministic, standard-library-only Python. It writes the fixed name to `/output/entry.txt`:

```sh
python3 main.py
cat /output/entry.txt
# MyExTookTheRouterAndTheDog
```
